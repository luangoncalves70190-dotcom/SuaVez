# Roteiro rápido de apresentação

1. Problema: falta de previsibilidade e informação durante a espera hospitalar.
2. Solução: localizar unidades, acompanhar fila, estimativas e alertas.
3. Paciente: hospitais próximos, fila, posição, tempo e alertas.
4. Administrador: dashboard, usuários, hospitais, filas e indicadores.
5. Dados: sistema → banco operacional → ETL → Star Schema → análises.
6. Tecnologias: React, TypeScript, NestJS, Firebase, Python/Pandas, Random Forest, PySpark e MySQL.
